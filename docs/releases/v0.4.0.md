# sysobs v0.4.0 — 2026-10-22

The menu-bar app, and the repository made ready for public readers. Baseline
`3ca7fbd` (v0.3.0).

## What changed

- **SysObs.app** (`app/`, bundle `com.redjay.sysobs`, app version 0.1.0): the
  latest snapshot and the machine-wide picture, the top processes by CPU and
  by memory from the newest light sample, the last hour's starts and exits,
  "Take a Snapshot Now", and a Settings window (refresh interval, list
  length). It reads the tails of `snapshot.csv`, `host_sample.csv` and the
  procwatch spool and runs `sysobs light --json`; it is never a writer. The
  parsing and every phrase shown live in the `SysObsCore` library, covered by
  35 XCTest checks on fixtures cut from a real store. Built, ad-hoc signed
  and installed to `~/Applications` by `app/build.sh`; never launched unless
  `--launch`. [docs/menu-bar-app.md](../menu-bar-app.md).
- **README**: "What it looks like", with the output of `light`, `events`,
  `show`, `top` and `list` from a real store with the command lines made
  generic; "Menu bar", with the app's build steps.
- **Fixtures**: the SysObsCore test fixtures no longer carry a personal home
  path.

`git pull && ./install.sh` (the symlink install picks the new file up at
once; the sampler reads it on its next tick). The app: `bash app/build.sh`.
